# Placard

Open-source social image renderer for creating consistent, branded SVG and PNG cards from reusable templates.

[Web app](https://placard.witt.im) · [Documentation](https://placard.witt.im/intro) · [中文文档](https://placard.witt.im/zh/intro) · [Releases](https://github.com/unix/placard/releases)

Placard helps teams create consistent social images for blog posts, product pages, release notes, and other shareable content. Choose a template, add your content and branding, then export the result or generate it automatically through the API.

## Features

- Reusable templates for consistent visual design
- Custom content, logos, and branding
- Live preview and SVG or PNG export
- HTTP API for automated image generation
- Self-hosting for full control over data and availability
